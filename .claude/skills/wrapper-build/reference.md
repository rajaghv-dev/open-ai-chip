## What config.json keys do (designs/user_project_wrapper/config.json, soc_itm identical but for the macro)
- `SYNTH_ELABORATE_ONLY true`, `RUN_POST_GPL_DESIGN_REPAIR false`, `RUN_POST_CTS_RESIZER_TIMING false`, `DESIGN_REPAIR_BUFFER_INPUT_PORTS false`, `PDN_ENABLE_RAILS false`, `RUN_ANTENNA_REPAIR false`, `RUN_FILL_INSERTION false`, `RUN_TAP_ENDCAP_INSERTION false`, `RUN_CTS false`, `RUN_IRDROP_REPORT false`, `ERROR_ON_SYNTH_CHECKS false`: macro-first hardening (the wrapper holds no cells; it only routes and builds the PDN).
- PDN: `PDN_VOFFSET/HOFFSET 5`, widths 3.1, spacing 15.5, pitch 180, `PDN_CORE_RING true` with ring offsets 12.45, spacing 1.7. `ERROR_ON_PDN_VIOLATIONS false`.
- `PDN_MACRO_CONNECTIONS ["mprj vccd1 vssd1 vccd1 vssd1"]`: the template example used vccd2/vssd2; our macros are on user area 1 supply.
- `MAX_TRANSITION_CONSTRAINT 1.5` (template wrapper-level value) is why the wrapper reports 0 slew violations; this says nothing about the macro's own slew.
- `DRT_THREADS 1`, `MAGIC_DRC_USE_GDS true`, `CLOCK_PORT wb_clk_i`, `CLOCK_PERIOD 25`.
- MACROS `lib` is mapped per corner (`*_tt_*`, `*_ss_*`, `*_ff_*` to nom_tt_025C_1v80, nom_ss_100C_1v60, nom_ff_n40C_1v95) so STA at each corner uses the matching macro liberty; if the export lacks ss/ff libs, use the single `*` entry for nom_tt (UPSTREAM.txt change 3). `find_reusable_run.py --export-views` errors "lib/<corner>/<m>__<corner>.lib missing" otherwise.
- `dir::../../build/macros/...` paths are skipped by the "config" test (generated by `make views`); other `dir::` paths must exist (`tests/run_tests.sh` "== config").
- A wrapper's `find_reusable_run.py` run is stale once any macro view changed (find_reusable_run.py header, "Macros:"), and `UPSTREAM.txt` counts as a flow input (soc_itm NOTES.md "Run time": a first attempt failed gl_final only because UPSTREAM.txt was edited after the run started).

## Wrapper test generics (tests/run_tests.sh)
- `WRAPS` = every `designs/user_project_wrapper*/` with a `config.json` (line 31). "== config": DESIGN_NAME must equal `user_project_wrapper` for any folder name starting with `user_project_wrapper`; MACROS has exactly one key that is a design here; `SYNTH_ELABORATE_ONLY` true; `RUN_LINT_CHECK`/`DISABLE_LVS` unset.
- "== rtl": iverilog -g2012 -Wall; a wrapper without testbench is linted alone.
- "== wrapper": parse the module body: exactly `[(<macro>, mprj)]` instances and no `assign`/`always`; header equal to `build/template/verilog/rtl/user_project_wrapper.v` (skipped with a note if absent); testbench must print a `PASS` line.
- "== notes": a wrapper with `output/metrics.json` needs the standard NOTES headings.

## Gate-level details
`scripts/flow/gl_sim.sh --netlist-extra FILE` (repeatable): extra gate-level source compiled right after the design netlist (the wrapper netlist has 0 std cells and just instantiates the macro). `--pre FILE`: compiled first (defines.v for MPRJ_IO_PADS). Script dies with "--netlist-extra file not found (run make views DESIGN=<macro>)" when views are missing. The Makefile builds `GL_NLX` from `MACROS` and `GL_PRE` from `%defines.v` in the RTL list. Gate-level uses sky130_fd_sc_hd functional models with unit delay.

## Undriven-output allowance (scripts/flow/signoff_allowances.json)
Schema in its `_what` field: `"designs": {"<folder name>": {"undriven_outputs": [...], "undriven_reason": "..."}}`; only Yosys "is used but has no driver" warnings on exactly those top-level ports are accepted. Both existing entries list `io_out`, `io_oeb`, `la_data_out` (128 + 38 + 38 = 204 bits). The reason cites the owner decision of 2026-10-06 (learning build) and the tapeout caveat: a floating `io_oeb` leaves the pad output enable undefined; before tapeout drive io_oeb high and io_out/la_data_out low from the macro, or confirm every user GPIO is configured as input in `user_defines.v`. Related, not done: GPIO startup modes for pads 5..37 (`rtl/user_defines.v` is the template's; pads 8..21 would be core outputs) and the ChipFoundry precheck (`designs/user_project_wrapper/README.md` "Not done").

## Failure history (designs/user_project_wrapper/README.md "How it got clean")
1. Lint failed: LibreLane lints the wrapper against the macro netlist with power pins defined; config needed `pnl`, not only `nl`.
2. Global routing congestion: first macro 400 x 400 um with 361 pins on its bottom edge 16 um above the wrapper's pin row, placed at [59.8, 16.32] (UPSTREAM.txt HISTORY). Fix: 109-pin macro (Wishbone + irq), pins on S edge in pad order, 250 x 250 um, at [189.06, 87.04] so wires are short and one full strap group (all 8 nets) crosses it. The earlier 400 x 400 um / 609 I/O macro had 3521 std cells, 2115 taps; the 250 um one has 1809 (tiny_ai_core NOTES.md "Why simplifying the pins halved the cell count").
3. Hold -0.894 ns plus 40 unpowered antenna diodes added by the router (LVS 70 errors, nwell DRC): macro hardened with default constraints and long input wires. Fix: Caravel macro SDC (clock latencies 4.65 to 5.57 ns, Wishbone input delays) for PNR and SIGNOFF, short wires. Result hold +0.105 ns. Later wrapper (soc_itm) NOTES: `RUN_ANTENNA_REPAIR` false so nothing inserted.
4. Macro build out of memory: 70 % slew margin chased input nets that already exceed the limit (Caravel input transition 0.84 / 0.92 ns on wbs_dat_i / wbs_adr_i vs 0.75 ns limit). Fix 20 %; 40 % gave 247 violations, 20 % gave 195 (designs/tiny_ai_core/config.json `//SLEW`, tiny_ai_core NOTES.md). Those are environment-limited.
5. Signoff flagged 204 undriven outputs: accepted in signoff_allowances.json with reason.
Pure copy case (soc_itm): same wrapper, same footprint and pin order, so placement, PDN crossing and routing repeat; route DRC converges one iteration sooner (50, 5, 0 vs 51, 6, 1, 0); timing differs only through the macro's liberty/SPEF (setup +2.965 vs +1.461 ns; designs/user_project_wrapper_soc_itm/NOTES.md).
