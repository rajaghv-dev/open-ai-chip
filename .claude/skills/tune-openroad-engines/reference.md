# tune-openroad-engines reference

Every key below was checked against the LibreLane 3.0.2 variable list of the pinned image
(`examples/hermes_desktop/tool_server/whatif_keys.json`, generated by `scripts/flow/gen_whatif_keys.py`); defaults come from the library or, for PDK
variables, from a flow run's `resolved.json` (for example `designs/vision_block/runs/RUN_*/resolved.json`). "repo value" is what the 25 committed configs use and the reason comes
from their `"//KEY"` comments. Deprecated spellings still seen in the configs (`PL_RESIZER_MAX_SLEW_MARGIN` = `DESIGN_REPAIR_MAX_SLEW_PCT`) are listed as aliases and accepted by the tools.
The `param_info` tool returns the same facts live, with the current value of a chosen design.

Verification columns name the evidence file: `metrics.json` is `designs/<d>/output/metrics.json` (committed) or `build/whatif/<d>__<tag>/runs/<tag>/final/metrics.json` (a what-if);
step logs are `<run>/NN-openroad-*/*.log`; reports are `designs/<d>/output/reports/*`.

Safety: the tools block these categories whatever the value (see `whatif_tools.check_key`): CLOCK_PERIOD / MAX_TRANSITION_CONSTRAINT above the current value, negative slack margins,
`*_ALLOW_SETUP_VIOS` true, signoff `RUN_*` off, `ERROR_ON_*` false, corner lists, `MAGIC_*` / `KLAYOUT_*` / `LVS_*` / `RCX_*` / `STA_*` settings, design files and nets, and on the Caravel wrappers every geometry key.
